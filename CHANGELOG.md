# Changelog

Perubahan penting pada proyek antislop dicatat di sini.

## [2.0.0] - 2026-10-24

### Added

- Panduan penulisan adaptif yang lebih mendalam.
- Mekanisme penyuntingan minimal.
- Diagnosis pola AI-slop berdasarkan konteks.
- Panduan akademik, profesional, dan kreatif.
- Spesifikasi 36 kasus pengujian regresi.
- Ikon SVG untuk tema terang dan gelap.

### Changed

- Penyempurnaan instruksi WRITE, REWRITE, dan REVIEW.
- Penguatan perlindungan fakta, angka, sitasi, dan makna.
- Penyesuaian metadata dan identitas plugin.

### Notes

- Kasus regresi belum seluruhnya diuji pada runtime ChatGPT.
- Tidak ada dependency eksternal.
